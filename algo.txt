STEP 7: Generate the n × n matrix and display it.STEP 8: Send the order n to the server using send().

STEP 11: Display the received matrix type.

ALGORITHM (SERVER PROGRAM)
STEP 1: Start the program.
STEP 2: Include the required header files for socket programming.
STEP 3: Create a TCP socket using socket().
STEP 4: Define the server address structure.
Set address family as AF_INET.
Set port number as 9002.
Set IP address as INADDR_ANY.
STEP 5: Bind the socket to the specified port using bind().
STEP 6: Put the socket into listening mode using listen().
STEP 7: Accept the client connection using accept().
STEP 8: Receive the order n from the client using recv().
STEP 9: Receive the matrix elements from the client using recv().
STEP 10: Initialize three flags:
upper = 1
lower = 1
diagonal = 1
STEP 11: Check whether all elements below the principal diagonal are zero.
If any non-zero element is found below the diagonal, set upper = 0.
STEP 12: Check whether all elements above the principal diagonal are zero.●​
If any non-zero element is found above the diagonal, set lower = 0.
STEP 13: Check whether all non-diagonal elements are zero.
If any non-zero element is found outside the principal diagonal, set
diagonal = 0.
STEP 14: Determine the matrix type:
If diagonal = 1, the matrix is a Diagonal Matrix.
Else if upper = 1, the matrix is an Upper Triangular Matrix.
Else if lower = 1, the matrix is a Lower Triangular Matrix.
Otherwise, the matrix is a Normal Matrix.
STEP 15: Send the matrix type to the client using send().
STEP 16: Close the client socket and server socket using close().
STEP 17: Stop.
